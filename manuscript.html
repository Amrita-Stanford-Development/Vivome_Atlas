Training Regimes & Performance

Unsupervised (0% labels)

~70% accuracy

Pure distribution matching using MMD, entropy minimization, and domain-adversarial training. Temperature-controlled contrastive learning discovers natural cell type clusters.

MMD Loss Entropy Min Domain Adversarial

Semi-Supervised (1-10% labels)

~85% accuracy

Limited supervision with supervised contrastive loss on labeled data and unsupervised alignment on unlabeled. Demonstrates remarkable label efficiency.

Partial Labels SupCon Loss Progressive Learning

Fully Supervised (100% labels)

~95% accuracy

Complete supervised contrastive learning achieving >90% kNN transfer accuracy and >95% centroid similarity across all modalities.

Neural Encoder Design & Architecture

MLPEncoder: Bottleneck Architecture

Each modality encoder compresses high-dimensional space to 128D representation

Input: Cell × Gene Matrix (n_cells, n_genes)
├── MLP Backbone: Linear(genes → 1024) + LayerNorm + GELU + Dropout(0.1)
├── Hidden Layer: Linear(1024 → 512) + LayerNorm + GELU + Dropout(0.1)
├── Projection: Linear(512 → 128) + LayerNorm
├── L2_Normalize(dim=-1) → Unit Sphere
Output: Cell × Latent Matrix (n_cells, 128)

HubModelNet Components

  • RNA Encoder: MLPEncoder for transcriptomics
  • Protein Encoder: MLPEncoder for proteomics
  • Shared Classifier: Linear(128 → n_classes)
  • Dual outputs: Embeddings + logits per modality

Key Design Principles

  • Modality-specific: Separate encoders per data type
  • Shared latent space: 128D for all modalities
  • L2 normalization: Enables cosine similarity
  • No cell pairing: Label-based alignment only

Supervised Contrastive Loss

Key Innovation: Cross-modal alignment without cell pairing - only requires matching cell type labels

Loss Formulation

L_SupCon = -log[ Σ(exp(sim(z_i, z_p)/τ)) / Σ(exp(sim(z_i, z_n)/τ)) ]

where:
• z_i = anchor embedding (from RNA)
• z_p = positive embeddings (same cell type, different modality)
• z_n = negative embeddings (different cell types)
• sim(a,b) = cosine similarity
• τ = temperature (0.1 default, 0.2 for stronger alignment)

Cross-Modal Only

Positive pairs must be from different modalities (RNA ↔ Protein) with same label. Same-modality pairs are excluded to enforce cross-modal alignment.

Pull-Push Dynamics

Pull same-type cells together (numerator), push different-type cells apart (denominator). Temperature controls sharpness of similarity distribution.

Two-Stage Training Pipeline

Progressive Learning: Foundation building followed by cross-modal alignment

Stage 1: RNA Warmup

10 epochs, protein encoder frozen

L = CrossEntropy(RNA_logits, labels)

Establishes strong RNA representation before introducing cross-modal training

Stage 2: Joint Training

90 epochs, all modalities active

L = λ_RNA×CE(RNA) + λ_PROT×CE(PROT) + λ_SupCon

Simultaneous classification and cross-modal alignment with weighted loss components

Evaluation & Validation Strategy

Multi-Metric Validation

Within-Modality

Classification accuracy on RNA and Protein test sets using respective encoders

Cross-Modality

kNN label transfer accuracy (Protein test → RNA train embeddings, k=5)

Centroid Analysis

C_rna = mean(normalize(Z_rna[Y==c]))
C_prot = mean(normalize(Z_prot[Y==c]))
similarity = C_prot @ C_rna.T

Measures alignment quality via class centroid cosine similarity

Early Stopping

  • Monitor: Mean validation accuracy
  • Patience: Configurable epochs
  • Restore: Best model weights
  • Prevents: Overfitting to training data
