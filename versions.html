Current release

Architecture change in progress

The reference is moving from CrossModalNet, a single model jointly trained on RNA and proteomics together, to a frozen RNA-only reference with a separately trained query encoder. This is a structural change, not a metric update — the joint model could implicitly see SCoPE2 during training, which is part of why its zero-shot numbers below read higher than the honestly separated architecture's will. Both sets of numbers are real; they answer different questions, and the lower number once it exists is the trustworthy one, not a regression.

The new architecture is decided, not yet trained: a five-seed comparison over the widened 9,002-gene feature space settled on a module-pooling encoder under uniform masking. The reference itself — reference_model.pt, reference_embedding.npy, reference_centroids.npy — still needs the full training run before the projection service can serve real predictions; see the projection page.

Data availability

Release protocol

  1. Freeze inputs: record accession numbers, download dates, and checksums for every dataset.
  2. Train and export, then regenerate the manifest with python3 tools/build_manifest.py.
  3. Bump ATLAS_VERSION in tools/build_manifest.py and commit the regenerated manifest.
  4. Tag the release and archive it for a persistent identifier.
  5. Record label stability against the previous version and add it to this page.

Label stability across versions is not yet measured. It is reported here from the first release that has a predecessor to compare against.
