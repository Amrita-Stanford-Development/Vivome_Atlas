Protein cells in this atlas cover only part of the label space. Cell types marked RNA only have none here, so their place in this view is not a cross-modal result; how the model does on them with real protein data is on the Manuscript page.

Use your own copy of the service

Run it from a clone of the repository, then enter its address (http://127.0.0.1:8001):

Send a matrix

Send mixed cells, such as PBMCs, in one file. Each gene is scaled within the file you send, so a single sorted population loses the contrast the model needs (known limits).

Up to   cells and   MB per file. Or drop a file on the map.
