Standing benchmark

Fixed datasets, fixed metrics, and every method scored the same way.

What it shows

  • On data no method was developed on, VivOME is level with the best simple baselines, not ahead of them. On Khoury 2026, the best guess of   ties PCA and scANVI with nearest-neighbour transfer, and is ahead of every other method and rule.   is not scored there yet: each use of Khoury 2026 needs the owner's decision.
  • Its lead on Fulcher 2026 is in-sample. The one tuned setting was chosen on these data, and   was checked on them.
  • No method separates SCoPE2's macrophages from its monocytes. VivOME is below chance there, and on the reprocessed matrix every method is at or below chance.
  • What VivOME adds is its answers. Beside its best guess, each cell gets an answer at the level the evidence supports, or an abstention with its reason. No baseline does this, so that part is not compared here; it is on the model card.
  • The claim that VivOME beats these methods waits for a sealed test on cells sorted by type. No public dataset has such cells yet.

How it is scored

  • Same inputs. Every method gets the same RNA reference, the same genes and the same query cells. VivOME and the correlation baseline are fixed before they see the query; PCA, Harmony, scANVI, MaxFuse, scGLUE and Seurat embed the query together with the reference.
  • Fair settings. A review found our first setup handicapped several baselines, so they were rerun with corrections fixed before any result: the RNA side scaled with every cell type weighted equally, MaxFuse with the settings of its own tutorial, and scANVI given inputs its likelihood can fit (research/benchmark/baseline-corrections.md).
  • Each method's own rules. Embeddings are scored with a shared nearest-neighbour rule, on the development data also with nearest centroid, and each tool with its own transfer where it has one.
  • Scores are balanced accuracy, or lymphoid recall on PBMC240: the mean over a method's seeds, with the SD and range below it.
  • The last column is VivOME's score minus each run's, from a paired bootstrap: 2,000 resamples stratified by true type, with a 95% interval. A run is counted as favouring one side only when the interval excludes zero.
  • Sources: research/benchmark/results.md and the tables beside it; the code is in benchmark/.
