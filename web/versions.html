Current release

Architecture change: complete

The reference moved from CrossModalNet, a single model jointly trained on RNA and proteomics together, to a frozen RNA-only reference with a separately trained query encoder. This was a structural change, not a metric update: the joint model could implicitly see SCoPE2 during training, which is part of why its zero-shot numbers below read higher than the honestly separated architecture's do. Both sets of numbers are real; they answer different questions, and the lower number is the trustworthy one, not a regression. The same argument explains the drop in the pca_centroid_cosine column of the diagnostics table for both cross-modal classes: the old jointly trained model's centroids trivially coincided across modalities, and the new frozen RNA-only reference never saw protein data during training, so its centroids no longer do. Read the current values in that table; this page does not copy manifest numbers into static text.

The architecture was decided by a five-seed comparison over the widened 9,002-gene feature space (module-pooling encoder, uniform masking; see the model card above for the settled details), and the reference is now trained with it: reference_model.pt, reference_embedding.npy, and reference_centroids.npy are real, live artifacts. The projection pipeline runs against them end to end; it is not yet deployed behind the projection page, which is a separate, still-open piece of work.

Prior baseline, kept rather than erased

Projection service model card

The reference encoder is trained, supervised, on RNA only: 85,233 cells across 22 immune/blood cell classes. It is applied zero-shot to proteomics uploads: no protein labels and no paired RNA-protein cells were used at any point in training. Full detail, sources, and the numbers below: service/model/MODEL_CARD.md.

A previously published RNA→RNA figure of 95.5% / 74.8% is superseded by the 93.2% / 65.7% figures above. The published number's test split included cells the model had trained on.

The restricted 79.8% is v3_seed0's own number, and is exact for SCoPE2 by construction, on two separate counts. First: SCoPE2's protein cells are only ever macrophage or monocyte, so restricting to exactly those two classes matches its true label set on this one dataset. On other data with other cell types present, the same restriction is wrong (see failure mode 1). Second: v3_seed0, the checkpoint actually running in production, is the best of five independently trained seeds of the same architecture by a wide margin (79.8% vs. a 5-seed mean of 71.5% ± 10.6, range 59.0–88.4).

Against scArches/scANVI, the strongest available cross-modal baseline, the shipped checkpoint's restricted-regime lead is real (it beats every scANVI seed under every protocol tested) but does not generalize: averaged across all 5 seeds, the architecture's shared-kNN-rule restricted mean (71.5%) trails scANVI's 3-seed mean (77.15%): only 3 of 15 seed-pairings favor this architecture there, 12 favor scANVI. The one regime it reliably wins is unrestricted (12 of 15 pairings, mean margin +18.1 points). Full breakdown: research/notebook-outputs/nb1d/paired_bootstrap_ours_vs_scanvi.csv, narrative in research/benchmark/results.md. A methodological asymmetry in scANVI's favor throughout this comparison: scANVI trains on the query cells (transductive); this encoder is fixed and zero-shot on the query.

Known failure modes:

  1. Two-class label space, now opt-in: when a request restricts labels to the supported classes, a non-myeloid protein upload (T cell, NK cell, B cell, etc.) can only ever be labelled macrophage, monocyte, or abstain, never its true label. The default now assigns among all 22 classes; that is an interim fix, not a solution (see the model card).
  2. Macrophage placement: cross-modal alignment is weak for macrophage specifically (latent centroid cosine 0.19 vs. 0.83 for monocyte; protein-side recall 0.76%), even though the macrophage-vs-monocyte ranking itself is correct (AUC 0.928).
  3. Only 2 of 22 reference classes (macrophage, monocyte) have ever been validated against real protein data.
  4. No donor-level holdout in training: all nine donors contributed about 65% of their own cells to the training set.
  5. High seed-to-seed variance on real cross-modal transfer, not yet explained: retraining the same architecture moves SCoPE2 restricted balanced accuracy by up to 29 points (59.0–88.4% across 5 seeds); the shipped seed happens to be the best of the five, not a principled choice. A separate development-only check on real PBMC240 data (lineage level) shows the same pattern; see service/model/MODEL_CARD.md for the full detail.

Data availability

Release protocol

  1. Freeze inputs: record accession numbers, download dates, and checksums for every dataset.
  2. Train and export, then regenerate the manifest with python3 scripts/build_manifest.py.
  3. Bump ATLAS_VERSION in scripts/build_manifest.py and commit the regenerated manifest.
  4. Tag the release and archive it for a persistent identifier.
  5. Record label stability against the previous version and add it to this page.

Label stability across versions is not yet measured. It is reported here from the first release that has a predecessor to compare against.
